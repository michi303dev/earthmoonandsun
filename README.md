# earthmoonandsun

Version 0.1 — HTML / CSS / JavaScript / Canvasのみで動く天体の軌跡アート。

## 起動

`index.html`をPCのブラウザで開くだけで自動再生します。ビルド・インストールは不要です。
スマートフォンでは、このフォルダーを静的Webサーバーで配信してアクセスしてください。

## 仕組み

- 太陽は中央固定。地球は6秒、月は `6 × 27.3 / 365.25 ≒ 0.44846` 秒で公転します。
- 画面の短辺から両公転半径を計算し、すべての天体と軌跡を画面内に収めます。
- 1/240秒刻みで地球と月の画面上の絶対座標を記録します。月は地球の移動と月自身の公転を合成します。
- 地球は直近6秒、月は月公転3周分（直近約1.35秒）の履歴だけを線で結び、古い位置ほど透明に描画します。
- requestAnimationFrameで描画し、高解像度画面にも対応します。リサイズ時は半径を再計算して履歴をリセットします。
- タブが非表示の間は作品内の時間を停止します。

## 確認

1. `index.html`をChrome / Edge / Firefox / Safariなどで開きます。
2. 6秒ほど待ち、地球の軌跡が1周分になり、月の短い合成軌跡が更新され続けることを確認します。
3. ウィンドウを縦長・横長に変更し、描画が収まり続けることを確認します。
4. 開発者ツールのデバイス表示でスマートフォンの画面幅・縦横方向を確認できます。
